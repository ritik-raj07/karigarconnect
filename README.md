# KarigarConnect / कारीगरकनेक्ट

A simple frontend demo for a local worker-booking platform.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. For best results, use VS Code + Live Server.
4. Internet is needed for the OpenStreetMap/Leaflet map.

## Included
- Bilingual English / Hindi labels
- 14 services with indicative hourly/daily rates
- Worker / कामगार and Customer / ग्राहक login interfaces
- Locality-based nearby worker listing
- Booking date, time, duration and location
- Wage calculator + local travel charge
- Mock payment interface
- Rating system and demo rating-based payout multiplier
- 9 AM–6 PM worker availability with tiffin break
- 20–25 minute request-switching concept (demo UI uses 20 seconds)
- Contact: 8292292822 / ayush12@gmail.com

## Important
This is a frontend prototype. Real OTP authentication, database, live worker GPS, actual payment gateway, push notifications and automatic 20–25 minute server-side reassignment require a backend.

The displayed wages are indicative demo market rates for India and should be reviewed for the target city/state before production use.
